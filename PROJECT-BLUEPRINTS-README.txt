KIRAN PORTFOLIO — PROJECT PLACEHOLDERS

All four HR case studies are intentionally labelled as planned and not yet completed. The project cards open a blueprint containing proposed deliverables, tools to consider, and a build checklist. These are planning prompts, not claims that the work has been completed.

1. Workforce Intelligence Dashboard
   Deliverables: clearly labelled synthetic employee dataset, Excel or Power BI dashboard, department/tenure charts, short insight summary, limitations/privacy notes.
   Suggested tools: Excel first; Power BI optional after completing an Excel version.

2. Recruitment Funnel Analysis
   Deliverables: synthetic candidate pipeline dataset, stage-by-stage funnel table, conversion/drop-off calculations, funnel chart, findings and recommendations.
   Suggested tools: Excel tables, formulas, lookups, PivotTables and charts.

3. Employee Onboarding Experience
   Deliverables: pre-boarding to day-30 journey map, onboarding checklist with owners/timing, document tracker, check-in questions and one-page process guide.
   Suggested tools: Excel or Google Sheets and a simple journey map.

4. Candidate Experience Journey
   Deliverables: candidate journey map, communication touchpoint matrix, sample emails, friction points and prioritised recommendations.
   Suggested tools: journey map or slide, plus a document containing sample messages.

Recommended order: Recruitment Funnel Analysis first, Workforce Intelligence Dashboard second, Employee Onboarding Experience third, Candidate Experience Journey fourth.

Important: use synthetic/anonymised sample data unless Kiran has explicit permission to share real data. Clearly label sample data and never claim hypothetical findings as real company impact. Update project status only when each deliverable is genuinely complete.

To preview locally, use the existing package scripts. Run `npm run build` to regenerate the `out/` folder before deploying. Preserve the current design and test the modals on desktop and mobile.
